# STC-TV-User-Behavior-Analysis-Recommendation-System
📌 Project Overview  This project was completed as part of the Data Analysis Virtual Work Experience Program offered by STC through the Misk Foundation.  The project explores user viewing behavior on a streaming platform, identifies content consumption patterns, forecasts future viewing trends, and recommends similar content based on user ratings.
🎯 Objectives

Analyze user viewing behavior and content preferences.

Compare viewing patterns across SD and HD video quality.

Identify viewing trends and recurring peak periods.

Forecast future viewing activity using time-series analysis.

Build a content recommendation system using collaborative filtering.

🛠️ Tools & Technologies

Python

Pandas — Data manipulation and analysis

Matplotlib / Plotly — Data visualization

Scikit-learn — Similarity calculations

ARIMA — Time-series forecasting

Google Colab — Development environment

📊 Project Tasks

1. User Behavior Analysis

Explored streaming data to understand content preferences, viewing duration, and consumption patterns across different program categories and video quality levels.

2. Time-Series Forecasting

Applied an ARIMA forecasting model to analyze historical viewing activity, identify recurring patterns, and estimate future viewing trends.

3. Recommendation System

Developed an item-item collaborative filtering approach using cosine similarity on a user-item rating matrix.

The system identified the following top five recommendations for users interested in Moana:

Trolls

Surf's Up: WaveMania

The Mermaid Princess

The Boss Baby

The Jetsons & WWE: Robo-WrestleMania!

4. Data Storytelling

Presented findings through visualizations and translated analytical results into recommendations to support content strategy and data-driven decision-making.
